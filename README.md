# Privacy Policy - PC Smart Utility

**Developer:** Omix Studios
**Last updated:** May 2026

## Overview

PC Smart Utility is a local Windows system monitor and IT toolkit. It does not collect, sell, or share personal data with any third party.

## Data Processed Locally (Never Transmitted)

All of the following is read locally on your device and displayed only to you — nothing is sent to any server:

- Hardware info (CPU, RAM, GPU, storage, BIOS)
- Installed software list
- Startup registry entries
- Environment variables
- Windows hosts file (read-only view)
- System serial numbers (displayed on screen only)

## Clipboard Monitoring

The app monitors clipboard content while it is open to display a session history list within the app. This data is held in memory only, never written to disk, never transmitted, and is cleared when the app closes.

## Internet Requests

The app makes one optional outbound HTTPS request to `api.ipify.org` — a public IP lookup service — only when the user clicks the "Fetch Public IP" button. No other data is included in this request. No response data is stored or transmitted further.

## No Telemetry, No Analytics, No Accounts

- No usage analytics
- No crash reporting to external servers
- No user accounts or sign-in required
- No advertising

## Contact

For questions or concerns: open an issue at the GitHub repository or contact Omix Studios via Microsoft Store publisher info.
